# 📄 AI PDF Chatbot using Groq + FAISS + Streamlit

An advanced AI-powered PDF chatbot that allows users to upload PDF files and ask questions from the documents using Retrieval-Augmented Generation (RAG).

---

# 🚀 Features

- 📂 Upload multiple PDF files
- 🤖 Ask questions from PDFs
- ⚡ Fast AI responses using Groq LLM
- 🔍 Semantic search with FAISS Vector Database
- 🧠 RAG (Retrieval-Augmented Generation)
- 🎨 Streamlit interactive UI
- 📑 Detailed and structured answers

---

# 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- Groq API
- FAISS
- FastEmbed
- PyPDF2

---

# 📸 Project Demo

## Upload PDF Files
Users can upload one or multiple PDF files.

## Ask Questions
Ask any question related to uploaded documents.

The chatbot generates detailed answers from the PDF context.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/vishalsl2675/pdf-chatbot.git
```

## Move to Project Folder

```bash
cd pdf-chatbot
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Add API Key

Create `.env` file:

```env
GROQ_API_KEY=your_api_key
```

---

# ▶️ Run Project

```bash
streamlit run app.py
```
